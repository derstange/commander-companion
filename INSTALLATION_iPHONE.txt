COMMANDER COMPANION VI — INSTALLATIONSANLEITUNG
===============================================

Dies ist eine Progressive Web App (PWA). Der ZIP-Inhalt wird auf einer
HTTPS-Webadresse veröffentlicht. Danach kann die App auf dem iPhone zum
Home-Bildschirm hinzugefügt werden und funktioniert nach dem ersten Laden
offline. Eine lokal aus der Dateien-App geöffnete index.html ist KEINE
installierte PWA — dafür ist HTTPS erforderlich.

A) VERÖFFENTLICHEN MIT GITHUB PAGES (kostenlos)
------------------------------------------------
1. ZIP-Datei auf dem PC entpacken (alle Dateien liegen im selben Ordner).
2. https://github.com besuchen, ggf. kostenloses Konto erstellen.
3. "New repository" auswählen, z.B. "commander-companion" als Namen,
   "Public" auswählen und Repository erstellen.
4. Im Repository "Add file" > "Upload files" anklicken.
   Die folgenden Dateien einzeln/zusammen aus dem entpackten Ordner hochladen:
   index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png,
   apple-touch-icon.png, die Wappen (crest-*.webp), die Ordner css/ und js/
   sowie .nojekyll (soweit beim System sichtbar).
   Wichtig: Dateien NICHT bloß als ZIP hochladen! Sie gehören direkt in
   das Stammverzeichnis des Repositorys, nicht in einen Unterordner.
5. Änderungen über "Commit changes" speichern.
6. In den Repository-Einstellungen "Settings" > "Pages" öffnen.
   Unter "Build and deployment" die Quelle "Deploy from a branch" wählen;
   Branch "main" und Verzeichnis "/ (root)" auswählen, dann "Save".
7. Nach der Veröffentlichung erscheint eine Adresse ähnlich dieser:
   https://DEIN-NAME.github.io/commander-companion/
   Diese Adresse auf dem iPhone in Safari öffnen.

B) AUF DEM IPHONE INSTALLIEREN
-----------------------------
1. Öffne die veröffentlichte HTTPS-Adresse in Safari (nicht aus Dateien).
2. Im Safari-Menü "Teilen" wählen und "Zum Home-Bildschirm" antippen.
3. Falls angeboten: "Als Web-App öffnen" aktivieren, dann "Hinzufügen".
4. Das neue Commander-App-Symbol auf dem Home-Bildschirm antippen.
5. Nach einem vollständig geladenen ersten Besuch und installierter
   Offline-Zwischenspeicherung funktioniert die App auch ohne Internet.

C) SPIELSTÄNDE, SICHERUNGEN, UPDATES
-----------------------------------
- Lebenspunkte und Turnier werden ausschließlich lokal auf dem Gerät im
  Browser gespeichert (kein Konto, kein Cloud-Sync). Der Dienst GitHub
  hostet nur den Code, NICHT deine Spielstände.
- Spiel und Turnier werden getrennt gesichert, jeweils als JSON-Datei:
  * Laufendes Spiel: im Spiel auf das Wappen tippen -> "Spiel sichern".
    Laden über "Spiel laden" im selben Menü oder über "Gespeichertes
    Spiel laden" auf dem Startbildschirm.
  * Turnier: in der Turnierübersicht "Turnier sichern" bzw.
    "Turnier laden"; vor dem ersten Turnier über "Gespeichertes Turnier
    laden" unter dem Formular.
  So lassen sich die Daten z.B. vom PC zum iPhone übertragen. Ältere
  Sicherungen (Spiel und Turnier in einer Datei) können weiterhin
  geladen werden; dabei wird jeweils nur der passende Teil übernommen.
- Eine frühere lokal geöffnete HTML-Datei teilt ihren lokalen Speicher
  nicht automatisch mit der neuen Internetadresse. Auf dem alten Gerät
  eine neue Sicherung machen, wenn die Version die Sicherung unterstützt.
  Die HTML-Version V hat noch keinen JSON-Export: Daten lassen sich aus
  ihr daher nicht einfach per Knopfdruck übertragen.
- Wenn eine neue Version veröffentlicht wird, können neuere App-Dateien
  bei Internetverbindung geladen werden. Bei Problemen App schließen,
  online erneut öffnen und bei Bedarf neu installieren.
- Browserdaten löschen, Privatmodus oder das Entfernen der Web-App kann
  die lokalen Daten verlieren lassen. Vor wichtigen Partien sichern.
- GitHub Pages Websites sind ÖFFENTLICH. Keine persönlichen/privaten
  Informationen als Dateien mit hochladen. Die JSON-Sicherungen gehören
  NICHT ins öffentliche Repository.

D) TURNIERABEND MIT EIGENEM SERVER (OPTIONAL)
--------------------------------------------
Mit einem Laptop oder Raspberry Pi im selben WLAN können alle Handys
dasselbe Turnier sehen: Tische starten, Sieger eintragen, und der Beamer
zeigt die Vollbild-Übersicht live mit QR-Code zum Mitspielen.
Anleitung: server/README.md. Ohne Server ändert sich nichts.
